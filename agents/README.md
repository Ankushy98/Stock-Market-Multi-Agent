# Autonomous Multi-Agent System for Stock Market News Analysis and Trend Prediction

## Project Description

This project develops an autonomous multi-agent AI system for analyzing stock market news, historical stock data, sentiment, technical indicators, and predicting short-term market trends.

## Objectives

- Collect stock market data
- Collect and analyze financial news
- Perform sentiment analysis
- Analyze technical indicators
- Use multiple AI agents for different tasks
- Predict short-term stock market trends
- Provide results through a dashboard

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)
- Machine Learning
- Multi-Agent Systems
- Streamlit
